# 3D Billboard Website

موقع لوحة إعلانية ثلاثية الأبعاد تفاعلي يشبه موقع WeAreInertia.

## المميزات

- ✨ **رسوميات 3D متقدمة** - آدم بن عمر للكهرباء – خبرة تتجاوز التوقعات في الأنظمة الكهربائيةباستخدام Three.js
- 🎨 **تصميم حديث** - واجهة مستخدم احترافية بـ Tailwind CSS
- 🎭 **حركات سلسة** - تأثيرات انتقالية جميلة باستخدام Framer Motion
- 🖱️ **تفاعل الماوس** - يتحرك اللوحة الإعلانية تابعة حركة الماوس
- 📱 **جاهز للجوال** - متجاوب مع جميع الأحجام
- ⚡ **أداء عالي** - محسّن للسرعة والأداء

## التكنولوجيا

- **Next.js 14** - إطار عمل React حديث
- **Three.js** - مكتبة الرسوميات ثلاثية الأبعاد
- **React Three Fiber** - تبسيط استخدام Three.js مع React
- **Tailwind CSS** - أنماط CSS حديثة
- **Framer Motion** - حركات وتأثيرات سلسة
- **TypeScript** - أمان النوع والإنتاجية

## التثبيت والتشغيل

### المتطلبات
- Node.js 16+
- npm أو yarn

### خطوات التثبيت

\`\`\`bash
# استنساخ المستودع
git clone <repository-url>
cd maximum

# تثبيت الحزم
npm install

# تشغيل الخادم التطويري
npm run dev
\`\`\`

تم! الآن يمكنك فتح \`http://localhost:3000\` في المتصفح.

### الإنشاء للإنتاج

\`\`\`bash
npm run build
npm start
\`\`\`

## المكونات

### Billboard3D
-آدم بن عمر للكهرباء – خبرة تتجاوز التوقعات في الأنظمة الكهربائية
- تتابع حركة الماوس
- إضاءة واقعية
- خلفية من النجوم
- تحميل الصور الديناميكي

### Header
- شريط التنقل العلوي

- معلومات عند التمرير
